# Portfólio Git

Bem-vindo ao meu portfólio de projetos utilizando Git.

## Descrição
Repositório criado para praticar o ciclo de vida local do Git, gerenciamento de arquivos e histórico de commits.

## Estrutura do Projeto
- `README.md`: Apresentação geral do portfólio
- `sobre.md`: Detalhes sobre o autor e trajetória profissional
- `contato.md`: Canais de comunicação e redes sociais

## Tecnologias Utilizadas
- Git
- Markdown

## Objetivos
- Praticar comandos de ciclo de vida local do Git
- Aprender a descartar alterações e corrigir histórico

Projetos desenvolvidos ao longo do aprendizado de Git:
